# freebuff-9router-provider — راهنمای فارسی

**استفاده از مدل‌های رایگان Freebuff (GLM 5.3 Flash و DeepSeek V4.1 Flash و MiMo 2.6 Flash و…) به‌عنوان یک Provider داخل [9router](https://github.com/decolua/9router)** — یا هر ابزاری که با API اوپن‌ای‌آی حرف بزند.

این پروژه **خودش روتر نیست**؛ یک سرویس کوچک محلی (بدون هیچ وابستگی، Node ≥ 18) است که:

1. یک‌بار با **جریان رسمی ورود Freebuff در مرورگر** (همان روش CLI رسمی) لاگین‌ات می‌کند،
2. یک اندپوینت **سازگار با OpenAI** روی `http://127.0.0.1:8787/v1` می‌سازد،
3. نشست (صندلی رایگان) را دقیقاً مثل کلاینت رسمی مدیریت می‌کند (دریافت، زنده‌نگه‌داشتن، آزادسازی)،
4. و `POST /v1/chat/completions` را به فرمت سیمی `/api/v1/chat/completions` خود Freebuff ترجمه می‌کند.

بعدش در **9router → Add Provider → OpenAI Compatible** آدرس بالا را اضافه می‌کنی و همه مدل‌های Freebuff کنار بقیه Providerهایت ظاهر می‌شوند.

## نصب

پیش‌نیاز: **Node.js نسخه ۱۸.۱۷ به بالا** (هیچ `npm install`ای لازم نیست) و یک حساب رایگان در freebuff.com.

```bash
git clone https://github.com/Godde3s/freebuff-9router-provider.git
cd freebuff-9router-provider
node bin/fb9r.js help
```

برای دستور سراسری `fb9r`:

```bash
npm link
```

## لاگین

```bash
fb9r login
```

- یک لینک چاپ می‌شود و مرورگر باز می‌شود.
- در سایت freebuff.com لاگین/ثبت‌نام می‌کنی و ورود را تأیید می‌کنی.
- اطلاعات ورود در `~/.config/freebuff-9router/credentials.json` ذخیره می‌شود (با سطح دسترسی `0600`).

اگر از قبل با CLI رسمی Freebuff لاگین کرده‌ای، اصلاً مرورگر لازم نیست:

```bash
fb9r import     # توکن را از ~/.config/manicode/credentials.json کپی می‌کند (فقط‌خواندنی)
```

## اجرای Provider

```bash
fb9r serve                    # پیش‌فرض: http://127.0.0.1:8787
fb9r serve --port 9000        # پورت دلخواه
fb9r serve --api-key mylocal  # اجباری‌کردن کلید برای درخواست‌های چت (توصیه می‌شود)
```

ترمینال باز بماند (یا با systemd / pm2 / tmux اجرا کن). با `Ctrl+C` **صندلی رایگان آزاد می‌شود** — این مهم است، چون هر حساب همزمان فقط یک صندلی دارد.

## اضافه‌کردن به 9router

1. در داشبورد 9router: **Providers → Add Provider → OpenAI Compatible**
2. پر کن:
   - **Name / ID**: `freebuff`
   - **Base URL**: `http://127.0.0.1:8787/v1`
   - **API key**: هر چیزی (مثلاً `fb9r-local`) — یا همان مقدار `--api-key`
3. مدل‌ها را اضافه کن (جدول پایین)، ذخیره کن و از صفحه Provider تست بگیر.
4. Claude Code / OpenCode / Hermes را مثل همیشه به 9router وصل کن و مثلاً مدل `z-ai/glm-5.3-flash` را بردار.

راهنمای کامل‌تر: [docs/CONNECT-9ROUTER.md](./docs/CONNECT-9ROUTER.md)

## کلاینت صادق — این ابزار چه کاری انجام نمی‌دهد

لایه رایگان Freebuff با تبلیغاتِ اپ‌های خودش تأمین می‌شود و سرورهایشCallerهای ثالث متخلف را بررسی می‌کنند. این پروژه آگاهانه سمت صادق خط می‌مانَد:

- **یک حساب، یک صندلی.** نه استخر توکن، نه گردشی چندحسابی.
- **فقط لاگین رسمی.** همان جریان مرورگرِ کد-در-آدرس؛ هیچ چیز دیگری.
- **پرامپت‌هایت دست‌نخورده می‌مانند.** حالت رایگانِ آپستریم لازم دارد اولین پیام system با هویت رسمی کلاینت Freebuff شروع شود (`You are Buffy, …`). این Provider فقط آن جمله را **به اول** پرامپت اضافه می‌کند و بقیه محتوایت را **دست‌نخورده** رد می‌کند. برخلاف بعضی پروژه‌های پراکسی، هیچ «پاک‌سازیِ نشان‌های ابزار خارجی» (Claude Code، Hermes، Aider و…) انجام نمی‌دهد — آن کار دورزدن تشخیص است؛ اگر آپستریم پرامپتی را رد کند، **خطای واقعی آپستریم** را می‌بینی.
- **بدون بازی با TLS/اثرانگشت.** یک شناسه تصادفی پایدار برای لاگین، شکل درخواست‌های عادی CLI، بدون ماژول استلث.
- **بدون رویداد تبلیغاتی جعلی.** تبلیغی نمایش نمی‌دهد و ایمپرشن ساختگی هم نمی‌فرستد.
- **محدودیت‌ها رعایت می‌شوند، نه دور زده:** Rate limit، سقف خرج، گیت کشور و بن — همه عیناً با `Retry-After` واقعی نمایش داده می‌شوند.

توضیح کامل: [docs/POLICY.md](./docs/POLICY.md)

## محدودیت‌ها و رفع اشکال

| علامت | معنی | کار |
|---|---|---|
| `429 rate_limited` | محدودیت واقعی آپستریم برای حساب تو | صبر تا `retryAfterMs` |
| `429 spend_limited` | سقف روزانه پر شده | ساعت ۱۲ شب به‌وقت Pacific ریست می‌شود |
| `403 country_blocked` | گیت منطقه/VPN | حالت رایگان از منطقه‌های مجاز؛ این ابزار لوکیشن جعل نمی‌کند |
| `session_superseded` (409) | کلاینت دیگری صندلی حساب را گرفته | CLI/Desktop دیگر Freebuff را ببند، دوباره تلاش کن |
| ردشدن پرامپت سیستمی «خارجی» | پرامپت ابزارت توسط آپستریم فلگ شده | این گیت خود Freebuff است؛ این Provider پرامپت را مبدل نمی‌کند |
| `401` از Provider | لاگین نیستی | `fb9r login` یا `fb9r import` |

نشست‌ها بعد از حدود ۱ ساعت خودبه‌خود تمام می‌شوند؛ این سرویس تا زمانی که روشن است زنده‌نگه می‌دارد و موقع خروج آزاد می‌کند.
