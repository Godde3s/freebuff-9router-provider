# freebuff-9router-provider — راهنمای فارسی

**استفاده از مدل‌های رایگان Freebuff (GLM 5.3 Flash و DeepSeek V4.1 Flash و MiMo 2.6 Flash و…) به‌عنوان یک Provider داخل [9router](https://github.com/decolua/9router)** — یا هر ابزاری که با API اوپن‌ای‌آی حرف بزند.

این پروژه **خودش روتر نیست**؛ یک سرویس کوچک محلی (بدون هیچ وابستگی، Node ≥ 18) است که:

1. یک‌بار با **جریان رسمی ورود Freebuff در مرورگر** (همان روش CLI رسمی) لاگین‌ات می‌کند،
2. یک اندپوینت **سازگار با OpenAI** روی `http://127.0.0.1:8787/v1` می‌سازد،
3. نشست (صندلی رایگان) را دقیقاً مثل کلاینت رسمی مدیریت می‌کند (دریافت، زنده‌نگه‌داشتن، آزادسازی)،
4. و `POST /v1/chat/completions` را به فرمت سیمی `/api/v1/chat/completions` خود Freebuff ترجمه می‌کند.

بعدش در **9router → Add Provider → OpenAI Compatible** آدرس بالا را اضافه می‌کنی و همه مدل‌های Freebuff کنار بقیه Providerهایت ظاهر می‌شوند.

## نصب

پیش‌نیاز: **Node.js نسخه ۱۸.۱۷ به بالا** (هیچ `npm install`ای لازم نیست) و یک حساب رایگان در freebuff.com.

```bash
git clone https://github.com/Godde3s/freebuff-9router-provider.git
cd freebuff-9router-provider
node bin/fb9r.js help
```

برای دستور سراسری `fb9r`:

```bash
npm link
```

## لاگین

```bash
fb9r login
```

- یک لینک چاپ می‌شود و مرورگر باز می‌شود.
- در سایت freebuff.com لاگین/ثبت‌نام می‌کنی و ورود را تأیید می‌کنی.
- اطلاعات ورود در `~/.config/freebuff-9router/credentials.json` ذخیره می‌شود (با سطح دسترسی `0600`).

اگر از قبل با CLI رسمی Freebuff لاگین کرده‌ای، اصلاً مرورگر لازم نیست:

```bash
fb9r import     # توکن را از ~/.config/manicode/credentials.json کپی می‌کند (فقط‌خواندنی)
```

## اجرای Provider

```bash
fb9r serve                    # پیش‌فرض: http://127.0.0.1:8787
fb9r serve --port 9000        # پورت دلخواه
fb9r serve --api-key mylocal  # اجباری‌کردن کلید برای درخواست‌های چت (توصیه می‌شود)
```

ترمینال باز بماند (یا با systemd / pm2 / tmux اجرا کن). با `Ctrl+C` **صندلی رایگان آزاد می‌شود** — این مهم است، چون هر حساب همزمان فقط یک صندلی دارد.

## اضافه‌کردن به 9router

1. در داشبورد 9router: **Providers → Add Provider → OpenAI Compatible**
2. پر کن:
   - **Name / ID**: `freebuff`
   - **Base URL**: `http://127.0.0.1:8787/v1`
   - **API key**: هر چیزی (مثلاً `fb9r-local`) — یا همان مقدار `--api-key`
3. مدل‌ها را اضافه کن (جدول پایین)، ذخیره کن و از صفحه Provider تست بگیر.
4. Claude Code / OpenCode / Hermes را مثل همیشه به 9router وصل کن و مثلاً مدل `z-ai/glm-5.3-flash` را بردار.

راهنمای کامل‌تر: [docs/CONNECT-9ROUTER.md](./docs/CONNECT-9ROUTER.md)

## API

بعد از بالا آمدن سرویس:

| مسیر | توضیح |
|---|---|
| `GET /` | نام، نسخه و فهرست اندپوینت‌ها |
| `GET /v1/models` | فهرست مدل‌ها به فرمت OpenAI (با نام مستعار و `created`) |
| `POST /v1/chat/completions` | چت، با `stream: true/false` |
| `GET /health` | وضعیت لاگین، نشست، حساب و نسخه |
| `DELETE /v1/session` | آزادسازی دستی صندلی (با تنظیم `--api-key`، همان کلید لازم است) |

خطاهای آپستریم **عیناً** با وضعیت HTTP واقعی رد می‌شوند: `429 rate_limited` / `spend_limited` / `ip_capped` با `retryAfterMs`؛ `country_blocked` روی 403؛ `model_locked` / `superseded` روی 409؛ `model_unavailable` روی 503؛ و اگر آپستریم کلاً جواب ندهد `504 upstream_timeout` می‌بینید. اگر وسط استریم خطا رخ دهد، یک فریم خطای استاندارد OpenAI قبل از `[DONE]` فرستاده می‌شود تا کلاینت بداند چرا استریم قطع شد.

## تست‌ها

```bash
npm test      # ۴۴ تست با آپستریم شبیه‌سازی‌شده — بدون نیاز به حساب
```

پوشش: پاکی و idempotent بودن envelope، جریان لاگین (با 401 در انتظار)، فایل اطلاعات ورود با دسترسی `0600` و import از CLI رسمی، admission/refresh/release صندلی، تعویض مدل، **mutex گذار صندلی زیر چت همزمان با مدل‌های مختلف**، نگاشت کامل خطاها (429/403/409/503 و رد‌شده‌های درون-200)، **تایم‌اوت 504 آپستریم (هم هدر هم بدنه)**، **انباشت‌نشدن لیسنر abort**، پاس‌sthrough سری، **فریم خطای وسط استریم**، تجمیع non-stream، **سقف حجم بدنه (413)**، گیت کلید محلی روی چت **و** آزادسازی نشست، و شکل OpenAI مدل‌ها.

## کلاینت صادق — این ابزار چه کاری انجام نمی‌دهد

لایه رایگان Freebuff با تبلیغاتِ اپ‌های خودش تأمین می‌شود و سرورهایش Callerهای ثالث متخلف را بررسی می‌کنند. این پروژه آگاهانه سمت صادق خط می‌ماند:

- **یک حساب، یک صندلی.** نه استخر توکن، نه گردشی چندحسابی.
- **فقط لاگین رسمی.** همان جریان مرورگرِ کد-در-آدرس؛ هیچ چیز دیگری.
- **پرامپت‌هایت دست‌نخورده می‌مانند.** حالت رایگانِ آپستریم لازم دارد اولین پیام system با هویت رسمی کلاینت Freebuff شروع شود (`You are Buffy, …`). این Provider فقط آن جمله را **به اول** پرامپت اضافه می‌کند و بقیه محتوایت را **دست‌نخورده** رد می‌کند. برخلاف بعضی پروژه‌های پراکسی، هیچ «پاک‌سازیِ نشان‌های ابزار خارجی» (Claude Code، Hermes، Aider و…) انجام نمی‌دهد — آن کار دورزدن تشخیص است؛ اگر آپستریم پرامپتی را رد کند، **خطای واقعی آپستریم** را می‌بینی.
- **بدون بازی با TLS/اثرانگشت.** یک شناسه تصادفی پایدار برای لاگین، شکل درخواست‌های عادی CLI، بدون ماژول استلث.
- **بدون رویداد تبلیغاتی جعلی.** تبلیغی نمایش نمی‌دهد و ایمپرشن ساختگی هم نمی‌فرستد.
- **محدودیت‌ها رعایت می‌شوند، نه دور زده:** Rate limit، سقف خرج، گیت کشور و بن — همه عیناً با `Retry-After` واقعی نمایش داده می‌شوند.

توضیح کامل: [docs/POLICY.md](./docs/POLICY.md)

## محدودیت‌های واقعی Freebuff

تمام موارد زیر از سورس عمومی خود Freebuff (`CodebuffAI/freebuff`) استخراج شده — حدس نیست. جزئیات کامل و انگلیسی: [docs/LIMITS.md](./docs/LIMITS.md).

**صندلی (نشست رایگان)**

- هر حساب همزمان فقط **۱ صندلی** دارد؛ هر نشست **حدود ۱ ساعت** عمر می‌کند و هر ۳۰ ثانیه (با لرزش ±۲۰٪) keepalive می‌شود.
- مدل وسط نشست **قابل تغییر نیست** — تعویض مدل یعنی آزادسازی و admission دوباره (این Provider خودش انجامش می‌دهد).
- اگر کلاینت دیگری (CLI رسمی، دسکتاپ، یک تب دیگر) با همان حساب صندلی بگیرد، نشست شما `superseded` می‌شود و چت جاری **409** می‌گیرد؛ این Provider صندلی را ریست می‌کند و تماس بعدی دوباره admission می‌گیرد.

**سهمیه‌ها (`rate_limited`)**

- مدل‌های **نامترشده** (بدون سهمیه): `glm-5.3-flash`، `deepseek-v4-flash`، `mimo`، `solar-mini4` — این‌ها پیش‌فرض درست برای کار روزمره هستند.
- مدل‌های **پریمیوم** از استخر سهمیه می‌خورند: طبق اعلان رسمی **۴ جلسه در روز / ۱۴ در هفته / ۴۰ در ماه** (ریست نیمه‌شب Pacific؛ هفتگی غلتان است).
- سهمیه جمع‌شوندنی است: پایه + معرفی دوستان (حداکثر **+۱ در روز**) + استریک + پرومو + سطح حساب.
- مدل‌های پریمیوم DeepSeek سقف **روزی یک‌بار** دارند (استخر جدا).
- خطا `rate_limited` همیشه `limit`، `recentCount`، `resetAt` و `retryAfterMs` دارد — یعنی سهمیه است، نه کندی؛ سریع بودن مشکل‌ساز نیست، پرخوری هست.

**پول**

- `spend_limited`: سقف خرج متقاطع؛ نسخه قدیمی سقف‌ها منسوخ شده و الان **سنجش Freebucks** (از 2026-09-02) جایش را گرفته — مدل‌های مترشده جلسه‌به‌جلسه هزینه Freebucks دارند. این Provider همیشه `cost_mode: "free"` و سقف خرج صفر می‌فرستد؛ **هرگز چیزی خرج شما نمی‌شود**.

**آی‌پی و جغرافیا**

- `ip_capped` (429): تعداد مشخصی **کاربر متمایز** همزمان روی یک IP خروجی مجازند (سقف `FREEBUFF_IP_USER_CAP`؛ عددش عمداً محرمانه است). با تمام شدن نشست هر‌کدام از آن کاربران رفع می‌شود — نه با ریست سهمیه. NAT مشترک (دفتر، خوابگاه، نود VPN) اول این را می‌بیند.
- `country_blocked` (403): حالت رایگان لیست مجاز کشور دارد؛ لوکیشن ناشناخته/ناشناس (VPN/پروکسی/تور — با سیگنال‌های حریم خصوصی IP) **قبل از شروع نشست** رد می‌شود. پایانی است؛ این ابزار هم لوکیشن جعل نمی‌کند.

**اعتماد حساب**

- حساب‌ها روی نردبان `new → verified → established → core` هستند؛ آستانه‌ها و ماتریس محدودیت **عمداً در ریپوی عمومی نیست** (نقل خودشان: «محدودیت منتشرشده، هدف منتشرشده است»). حساب جدید سخت‌گیرترین سهمیه را دارد و با گذر زمان/تأیید/رفتار سالم بازتر می‌شود.
- `banned` پایانی است و همه اندپوینت‌ها جوابش را می‌دهند. استفاده تک‌حسابی صادق بن نمی‌گیرد؛ ربات و استخر حساب می‌گیرد.

**پنجره‌های دسترسی مدل**

- `model_unavailable` (503): مدل‌های پیشنهاد محدود ساعات کاری «۹صبح تا ۵عصر ET» را دارند؛ پریمیوم DeepSeek در پنجره گرانِ **روزهای کاری (دوشنبه–جمعه به‌وقت پکن) ۰۰:۰۰–۱۰:۰۰ UTC** (مشتق از ساعات اوج رسمی DeepSeek) می‌ایستد و آخر هفته همیشه باز است؛ `gpt-6-luna` فقط آمریکا یا پلن پولی؛ `gemini-3.8-flash` پلن پولی؛ `minimax-m3` بسته به ظرفیت.
- `space-bunny-alpha` بتاست و **پرامپت‌ها را برای آموزش نگه می‌دارد** — چیزی خصوصی نفرست.

**گیت‌های چت (هر درخواست، سمت سرور)**

- `cost_mode: "free"` اجباری؛ جفت agent+model باید در لیست سفید `base3-free-*` باشد؛ اولین پیام system باید با هویت رسمی کلاینت Freebuff شروع شود (این Provider آن را **پیشوند** می‌کند و محتوایت را دست نمی‌زند)؛ پرامپت‌های دارای نشان ابزارهای شناخته‌شده (Claude Code، Hermes و…) ممکن است با `foreign_system_prompt` رد شوند — این Provider نشان‌ها را پاک نمی‌کند و خطای واقعی را نشان می‌دهد؛ شکل client_id هم بررسی می‌شود که اثر انگشت پراکسی نباشد.
- توکن refresh وجود ندارد؛ توکن که مُرد، دوباره `fb9r login`.

## آیا با یک پروکسی جدید مثل OpenCode حل می‌شود؟

**پاسخ کوتاه: نصفه‌و‌نیمه — و آن نصف مهمش نه.**

- **چیزی که پروکسی حل می‌کند: سازگاری.** ترجمه پروتکل (OpenAI/Anthropic ↔ Freebuff)، استریم، نام مدل، پشتیبانی از هر کلاینتی — این دقیقاً کاری است که همین Provider و 9router انجام می‌دهند و حل‌شده است. اگر مقایسه با OpenCode یعنی «لوله‌کشی»، بله — همان دارو اینجا هم خورده شده.
- **چیزی که پروکسی حل نمی‌کند: محدودیت‌های سمت سرور.** صندلی، سهمیه‌ها، سقف IP، گیت کشور، لیست سفید، سطح اعتماد و بن — همه سمت سرور و بر اساس سه ورودی محاسبه می‌شوند: **حساب تو، IP تو، شکل درخواست**. پروکسی جدید هیچ‌کدام از این سه را عوض نمی‌کند. تنها کار باقی‌مانده برای یک پروکسی، دورزدن تشخیص است: استخر چندحسابی (مستقیم به `ip_capped` و بن می‌رسد)، پاک‌کردن نشان‌های ابزارها (نقض کنترل دسترسی)، جعل TLS/اثرانگشت، بازی VPN (با `ipPrivacySignals` لو می‌رود). همه این‌ها نقض قوانین سرویس است، حساب می‌سوزاند، و این پروژه **آگاهانه از پیاده‌سازی‌شان امتناع می‌کند**. پس برای Freebuff، پروکسی جدید همان کاری را نمی‌کند که برای OpenCode تصور می‌شود — محدودیت‌های مؤثر روی سرور Freebuff живут، نه در کلاینت تو.

**راه‌های مشروع برای گرفتن سهم بیشتر:**

1. از مدل‌های **نامترشده** استفاده کن (GLM 5.3 Flash، DeepSeek V4 Flash، MiMo، Solar Mini 4) — دقیقاً برای همین پیش‌فرض رایگان گذاشته شده‌اند.
2. سهمیه را بالا ببر: **معرفی دوستان (+۱/روز)، استریک، سطح حساب** — همه روی ۴/۱۴/۴۰ اضافه می‌شوند.
3. پنجره‌ها را رعایت کن: `retryAfterMs`/`resetAt` عیناً نمایش داده می‌شوند؛ پریمیوم DeepSeek روزهای کاری ساعت ۱۰ UTC برمی‌گردد.
4. اگر لاین پریمیوم لازم داری: **اشتراک** (Starter/Plus/Pro) یا شارژ Freebucks — این همان چیزی است که با پول فروخته می‌شود.
5. بگذار **9router دور ممانعت‌ها مسیریابی کند**: وقتی Freebuff `rate_limited` داد، کار روتر افتادن روی Provider دیگری از Providerهای خودت است — مسیریابی بین Providerهای خودِ کاربر تعامل‌پذیری است، نه دورزدن.
6. برای کار سنگین: کلید رسمی (BYOK) یا API رسمی.

## رفع اشکال

| علامت | معنی | کار |
|---|---|---|
| `429 rate_limited` | سهمیه مدل‌های پریمیوم حساب تو تمام شده | صبر تا `retryAfterMs`، یا برو سراغ مدل نامترشده |
| `429 spend_limited` | سنجه Freebucks مدل مترشده را رد کرده | مدل نامترشده بردار، یا صبر کن، یا بالادستی شارژ/اشتراک |
| `429 ip_capped` | نشست‌های رایگانِ متمایزِ زیاد روی IP خروجی تو | با تمام شدن یکی از آن نشست‌ها خودش باز می‌شود — تنظیمی ندارد |
| `403 country_blocked` | گیت منطقه/VPN | حالت رایگان از منطقه‌های مجاز؛ این ابزار لوکیشن جعل نمی‌کند |
| `409 model_locked` / `superseded` | تداخل صندلی/کلاینت دیگر | CLI/Desktop دیگر Freebuff را ببند؛ صندلی خودش ریست می‌شود |
| `503 model_unavailable` | مدل بسته است (ساعات کاری / پنجره گران DeepSeek / ظرفیت) | مدل دیگری امتحان کن؛ پنجره‌ها در LIMITS مستند است |
| `504 upstream_timeout` | آپستریم اصلاً جواب نداد | گذراست — دوباره تلاش کن؛ دیگر تا ابد هنگ نمی‌کند |
| ردشدن پرامپت سیستمی «خارجی» | پرامپت ابزارت توسط آپستریم فلگ شده | این گیت خود Freebuff است؛ این Provider پرامپت را مبدل نمی‌کند |
| `401` از Provider | لاگین نیستی | `fb9r login` یا `fb9r import` |

نشست‌ها بعد از حدود ۱ ساعت خودبه‌خود تمام می‌شوند؛ این سرویس تا زمانی که روشن است زنده‌نگه می‌دارد و موقع خروج (`Ctrl+C` / `SIGTERM` / `DELETE /v1/session`) صندلی را آزاد می‌کند.
